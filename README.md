# MicroDUAL 🛸

MicroDUAL is a fast paced 2 player game for BBC micro:bit devices. Each player controls a spaceship and competes by shooting bullets at the opponent. Bullets travel between devices using the built-in radio module. If a player gets hit 5 times, they lose the match.

The game features real-time movement, shooting, collision detection, and cross-device communication.
